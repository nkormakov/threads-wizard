Peak Ø is measured across the tips of the thread, valley Ø across the bottoms of the grooves. Bolt peak = nominal size d; bolt valley d3 = d − 1.22687·P. Nut peak D1 = d − 1.08253·P (the bore, close to the tap drill size); nut valley D = d. Metric and Unified threads share the same 60° basic profile, so both use these formulas (P = 1/TPI for inch threads). Values are rounded to 3 decimals in mm and 4 decimals in inches. Coarse = UNC and fine = UNF for inch threads. Native units show metric threads in mm and inch threads in inches/TPI.

Re-tap check takes the smallest selected thread as an existing tapped hole and marks in red every thread that can't be cleanly tapped over it: its nut peak Ø (the new bore) is smaller than the existing hole's nut valley Ø, so the old grooves would stay in the new thread.
